隐私政策

最后更新: 2026-01-11

最后更新：2026 年 4 月 15 日

本隐私政策说明了 有心言者（https://zhurong2020.github.io，以下简称"本站"、"我们"）在您访问、浏览或以其他方式使用本站时，如何收集、使用、存储、共享和保护您的个人信息。请您在使用本站前仔细阅读并充分理解本政策。如您继续使用本站，即视为您已同意本政策全部条款。

一、网站运营者

本站由个人独立运营，作为博客文章的历史归档站，主要收录作者早期关于技术、学习、阅读与生活思考的记录。内容不代表任何机构或公司立场，所有观点仅为作者个人分享，供读者参考。

二、我们收集的信息

2.1 自动收集的信息

当您访问本站时，出于安全、统计和功能实现的需要，GitHub Pages 服务器及第三方服务可能自动记录以下信息：

  • IP 地址（由 Google Analytics 匿名化处理）、大致地理位置（城市/国家级）
  • 浏览器类型、版本与语言设置
  • 操作系统与设备类型（桌面/移动）
  • 访问时间、停留时长、访问页面、跳转来源（Referer）
  • 屏幕分辨率等用于响应式页面适配的技术信息

2.2 您主动提供的信息

在您通过评论系统（Gitalk，基于 GitHub Issues）与本站互动时，您可能提供以下信息：

  • GitHub 用户名与头像
  • 评论内容

评论数据由 GitHub 存储，受 GitHub 隐私政策约束。

2.3 Cookie 和类似技术

本站使用 Cookie 及本地存储（localStorage）等技术，以维持访问偏好、分析访问情况及投放相关广告。Cookie 是存储在您设备上的小型文本文件，您可以随时在浏览器设置中查看、禁用或删除 Cookie，但这可能影响部分功能的正常使用。

三、信息的使用目的

我们将所收集的信息用于以下合法目的：

  • 提供、维护和改进本站及其功能
  • 响应您的评论、咨询和反馈
  • 分析访问行为，优化内容质量与页面体验
  • 识别并防止垃圾评论、滥用、恶意访问等安全事件
  • 根据您的兴趣投放更相关的广告内容
  • 履行法律法规规定的义务

四、第三方广告与 Google AdSense

本站使用 Google AdSense（发布商 ID：ca-pub-3677908378517538）及其他经授权的第三方广告服务展示广告。Google 作为第三方厂商，会使用 Cookie（包括 DART Cookie）在用户访问本站及其他互联网站点时投放广告。

这些第三方广告服务提供商可能基于您访问本站及其他网站的历史信息，使用 Cookie、Web 信标、像素标签或类似技术收集并使用相关数据（不包括姓名、邮箱等可直接识别个人身份的信息），以便向您投放符合兴趣的广告。

您可以通过以下方式了解并管理相关设置：

  • 访问 Google 广告和隐私政策 了解详情
  • 访问 Google 广告设置 管理个性化广告偏好或选择退出
  • 访问 aboutads.info（DAA）或 NAI 选择退出第三方广告 Cookie
  • 欧盟用户可访问 Your Online Choices 管理相关偏好

五、Google Analytics

本站使用 Google Analytics (GA4 ID: G-WH117GE51W) 收集匿名的访问统计数据。Google Analytics 会使用 Cookie 来分析用户的使用情况。您可安装 Google Analytics 停用附加组件 阻止数据采集。

六、信息共享与披露

我们不会出售、出租或以交换形式对外提供您的个人信息。仅在以下情形下，我们可能共享必要的信息：

  • 服务提供商：向协助本站运营的第三方服务商（GitHub Pages、Google Analytics、Google AdSense、Gitalk/GitHub Issues 等）共享必要数据，这些第三方须按相应协议履行保密义务
  • 法律要求：根据有效的法律程序、法院命令、政府调查或为保护合法权益的必要情形
  • 征得同意：在您事先明确同意的情况下进行共享

七、数据保留期限

我们仅在实现上述收集目的所必需的期限内保留您的个人信息：

  • 评论数据：由 GitHub Issues 长期保留，除非您主动在 GitHub 删除相应 Issue 评论
  • Google Analytics 数据：默认保留 14 个月
  • GitHub Pages 访问日志：由 GitHub 按其服务政策管理

八、数据安全

本站由 GitHub Pages 托管，全站通过 HTTPS 加密传输。第三方服务商（Google、GitHub）均采用行业标准的安全措施保护数据。但请您理解，任何互联网传输或电子存储方式均无法保证绝对安全。

九、第三方链接

本站可能包含指向第三方网站或服务的链接（如 GitHub、arong.eu.org、YouTube 等）。这些第三方站点有各自独立的隐私政策，本站不对其内容、数据处理行为或隐私实践承担责任。建议您在访问第三方站点前阅读其隐私声明。

十、儿童隐私

本站的内容并非面向 13 岁以下（含）的儿童，我们不会有意收集此年龄段儿童的个人信息。若监护人发现儿童向本站提供了个人信息，请通过下文联系方式告知我们，我们将第一时间予以删除。

  • 知情权与访问权：了解并获取我们掌握的与您有关的个人信息副本

  • 删除权：在符合法定情形下要求删除您的个人信息（含 GitHub 上的评论）
  • 限制处理权：要求限制或反对特定的处理活动
  • 撤回同意权：撤回此前给予的处理同意
  • 投诉权：向相关监管机构提出投诉

您可通过下文联系方式行使上述权利，我们将在收到请求后 30 天内予以回复。
